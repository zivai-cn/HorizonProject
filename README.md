# 项目名称 HorizonProject

## 项目背景
华北理工大学robomaster实验室horizon战队的特招题目

## 工程环境
- MCU：STM32F407VGT6
- 开发板：梁山派天空星
- IDE：VSCode
- 开发工具：Ninja + CMake + arm-none-eabi-gcc
- 调试工具：Dap-Link

## 任务目标
选择⼀款通过 SPI 或 I²C 通信的六轴 MEMS IMU，完成数据解算与姿态融合。
可选型号包括 MPU6050、BMI088、ICM42688P、ICM45686、ICM42670 等。
硬件资源要求
STM32 系列任意单⽚机。
满⾜上述要求的任意 IMU。
USB 转 TTL 模块，或 STM32 ⾃带的 USB。
核⼼功能指标
（1）姿态解算
使⽤定时器或 FreeRTOS 任务触发读取 IMU 数据，或者采⽤中断⾃动触发读取。
实现滤波算法，解算出四元数，以及横滚、俯仰、偏航⻆度。
实现 IMU 的上电⾃校准和零漂抑制功能。
（2）板间通信协议
⾃定义通信协议。
从机每 1 ms（1000 Hz） 向电脑串⼝助⼿等上位机发送⼀帧包含“四元数/欧拉⻆”的数据包
